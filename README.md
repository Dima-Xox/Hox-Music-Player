# Hox — музыкальный плеер для Windows

**Hox** — лёгкий музыкальный плеер с караоке-режимом, визуализатором, темами оформления и лаунчером с автообновлением. Начиная с v0.6.0 написан на **Rust** (egui + rodio/symphonia) — статические бинари без внешних рантаймов: не нужны ни Python, ни Qt, ни VC++ Redistributable. Работает на Windows 10/11 (x64).

> ⚠️ Ранняя бета. Проект развивается, интерфейс и формат данных могут меняться между версиями.

## Возможности

- Караоке-режим с пословной подсветкой (LRC / enhanced A2) в стиле стриминговых сервисов: активная строка заливается слева направо, клик по строке — мгновенная перемотка (с учётом ручного сдвига), колесо мыши — сдвиг синхронизации;
- Библиотека музыки: сканирование папок (включая вложенные), разбор тегов и имён файлов, обложки, номера треков, сортировки, контекстные действия «Воспроизвести альбом» / «Играть все треки исполнителя» (альбом играется в порядке его треков);
- Мини-плеер поверх всех окон, эквалайзер-визуализатор, «Что нового» по версиям;
- Пять тем оформления: Aurora, Ember, Classic, Sunset, Emerald;
- Форматы: mp3, flac, ogg/vorbis, m4a/aac, wav (декодирование symphonia); перетаскивание файлов и папок, сохранение позиции и настроек между запусками (настройки C++-версии подхватываются автоматически);
- Лаунчер: авто-обновление себя и плеера с GitHub Releases (скачивание установщика, проверка SHA-256, тихая установка), уведомления-балун с описанием изменений, отложенный запуск обновления по расписанию и ожидание закрытия играющего плеера, проверка обновлений при запуске и каждые 4 часа, сворачивание в трей, одиночный экземпляр;
- Установка «из коробки»: бинари со статическим CRT — установщику не нужны VC++ Redistributable, UAC не запрашивается.

## Установка

1. Скачайте `Hox-Setup-<версия>.exe` со страницы [Releases](../../releases);
2. Запустите — Windows может показать предупреждение SmartScreen для неподписанного установщика: «Подробнее» → «Выполнить в любом случае»;
3. Установщик ставит плеер и лаунчер в `%LOCALAPPDATA%\Hoxmusicp` и создаёт ярлык **«Hox»** на рабочем столе и в меню **«Пуск»**;
4. Готово — плеер уже установлен, ничего скачивать из лаунчера не нужно. Обновления лаунчер ставит сам (авто-обновление), а если плеер был удалён — скачает и установит его заново с GitHub.

## Автообновление

Лаунчер при запуске, по кнопке «Проверить обновления» и каждые 4 часа (пока висит в трее)
обращается к GitHub Releases:

```
https://api.github.com/repos/Dima-Xox/Hox-Music-Player/releases/latest
```

Лаунчер сверяет релиз с версией именно установленного плеера (спрашивает её у самого `HoxPlayer.exe`).
Если вышел релиз новее — лаунчер **обновится сам**: скачает установщик, проверит SHA-256
(сайдкар `*.sha256` из релиза), тихо установит и перезапустится, после чего запустит свежий
плеер. Нажимать ничего не нужно — это и есть авто-обновление.

Чтобы обновление не мешало:

- если плеер сейчас играет, авто-установка откладывается до его закрытия — лаунчер проверяет
  каждые 90 секунд;
- установка проходит полностью без UAC: Rust-бинари не требуют VC++ Redistributable.

Авто-обновление можно выключить: правый клик по иконке лаунчера в трее → снять галочку
«Авто-обновление с GitHub» (настройка сохраняется). Кнопка «Обновить плеер до vX.Y.Z»
в окне лаунчера при этом продолжает работать.

**Уведомления о новых версиях.** При обнаружении релиза иконка в трее покажет балун
с кратким описанием изменений (один раз на релиз). Полный список — пункт «Что нового в vX.Y.Z»
в меню трея или кнопка в окне лаунчера, оттуда же можно открыть страницу релиза на GitHub.

**Отложенный запуск по расписанию.** Правый клик по иконке в трее → «Отложенное авто-обновление» →
«Сразу», «Через 1 час», «Через 6 часов» или «Через 24 часа». Обнаруженный релиз установится
в назначенное время — балун покажет когда. Расписание сохраняется и переживает перезапуск
лаунчера; смена пункта пересчитывает время, выключение авто-обновления отменяет установку,
а если в назначенный момент играет музыка — установка подождёт закрытия плеера.

Если плеера нет рядом с лаунчером (например, его удалили) — появится кнопка «Скачать плеер с GitHub»:
лаунчер скачает и тихо установит последний релиз без ручных действий.

## Проверка контрольных сумм (Windows)

```bat
certutil -hashfile Hox-Setup-0.5.0.exe SHA256
```

Сравните результат с содержимым `Hox-Setup-0.5.0.exe.sha256` из релиза.

## Исходники

- `cpp/` — C++-версия (v0.5.0+):
  - `cpp/src/player/` — плеер (Qt 6 Widgets + Multimedia);
  - `cpp/src/launcher/` — лаунчер;
  - `cpp/CMakeLists.txt` — сборка CMake;
- `installer/hox-setup-cpp.nsi` — скрипт установщика (NSIS 3, автоустановка redist'ов);
- `.github/workflows/build.yml` — автосборка Windows-установщика (MSVC + Qt 6.8 + NSIS);
- `src/` — исходная Python-версия 0.4.x (сохранена для истории и сборок под Windows 7).

### Сборка из исходников

Windows: Qt 6.8 (MSVC 2022), CMake 3.21+:

```bat
cmake -S cpp -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```

Запуск из исходников (Windows/Linux/macOS): `build/bin/HoxPlayer.exe` (или `HoxPlayer` на Linux).
Зависимости: Qt 6 (Widgets, Multimedia, Network), VC++ Redistributable на Windows (ставится установщиком автоматически).

## Удаление

«Параметры» → «Приложения» → Hox Music Player → «Удалить» — деинсталлятор убирает плеер, лаунчер и ярлыки.
