# Hox — музыкальный плеер для Windows

**Hox** — лёгкий музыкальный плеер с караоке-режимом, визуализатором, темами оформления и лаунчером с автообновлением. Начиная с v0.5.0 написан на **C++ (Qt 6)** — Python на машине пользователя не нужен. Работает на Windows 10/11 (x64).

> ⚠️ Ранняя бета. Проект развивается, интерфейс и формат данных могут меняться между версиями.

## Возможности

- Караоке-режим с пословной подсветкой (LRC / enhanced A2) в стиле стриминговых сервисов: активная строка заливается слева направо, клик по строке — мгновенная перемотка (с учётом ручного сдвига), колесо мыши — сдвиг синхронизации;
- Библиотека музыки: сканирование папок (включая вложенные), разбор тегов и имён файлов, обложки, номера треков, сортировки, контекстные действия «Воспроизвести альбом» / «Играть все треки исполнителя» (альбом играется в порядке его треков);
- Мини-плеер поверх всех окон, эквалайзер-визуализатор, сплэш-экран, «Что нового» по версиям;
- Пять тем оформления: Aurora, Ember, Classic, Sunset, Emerald;
- Медиа-клавиши (play/pause/next/prev), перетаскивание файлов и папок, сохранение позиции и настроек между запусками;
- Лаунчер: проверка обновлений с GitHub Releases при запуске, скачивание установщика с проверкой SHA-256, тихая установка через UAC, сворачивание в трей, одиночный экземпляр;
- Установщик сам проверяет и тихо ставит **VC++ Redistributable 2015–2022 (x64 и x86)** — один запрос UAC, на чистой системе плеер запускается сразу.

## Установка

1. Скачайте `Hox-Setup-<версия>.exe` со страницы [Releases](../../releases);
2. Запустите — Windows может показать предупреждение SmartScreen для неподписанного установщика: «Подробнее» → «Выполнить в любом случае»;
3. Установщик ставит плеер и лаунчер в `%LOCALAPPDATA%\Hoxmusicp` и создаёт ярлык **«Hox»** на рабочем столе и в меню **«Пуск»**;
4. Если в системе нет VC++ Redistributable, установщик предложит UAC и поставит его тихо (x64 и x86) — это разовая операция;
5. Готово — плеер уже установлен, ничего скачивать из лаунчера не нужно. Обновления лаунчер предложит сам.

## Автообновление

Лаунчер при запуске и по кнопке «Проверить обновления» обращается к GitHub Releases:

```
https://api.github.com/repos/Dima-Xox/Hox-Music-Player/releases/latest
```

Если вышел релиз новее — лаунчер покажет кнопку «Обновить до vX.Y.Z»: скачает установщик,
проверит SHA-256 (сайдкар `*.sha256` из релиза), запустит тихо через UAC и перезапустится.

## Проверка контрольных сумм (Windows)

```bat
certutil -hashfile Hox-Setup-0.5.0.exe SHA256
```

Сравните результат с содержимым `Hox-Setup-0.5.0.exe.sha256` из релиза.

## Исходники

- `cpp/` — C++-версия (v0.5.0+):
  - `cpp/src/player/` — плеер (Qt 6 Widgets + Multimedia);
  - `cpp/src/launcher/` — лаунчер;
  - `cpp/CMakeLists.txt` — сборка CMake;
- `installer/hox-setup-cpp.nsi` — скрипт установщика (NSIS 3, автоустановка redist'ов);
- `.github/workflows/build.yml` — автосборка Windows-установщика (MSVC + Qt 6.8 + NSIS);
- `src/` — исходная Python-версия 0.4.x (сохранена для истории и сборок под Windows 7).

### Сборка из исходников

Windows: Qt 6.8 (MSVC 2022), CMake 3.21+:

```bat
cmake -S cpp -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```

Запуск из исходников (Windows/Linux/macOS): `build/bin/HoxPlayer.exe` (или `HoxPlayer` на Linux).
Зависимости: Qt 6 (Widgets, Multimedia, Network), VC++ Redistributable на Windows (ставится установщиком автоматически).

## Удаление

«Параметры» → «Приложения» → Hox Music Player → «Удалить» — деинсталлятор убирает плеер, лаунчер и ярлыки.
