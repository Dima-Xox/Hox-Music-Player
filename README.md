# Hox — музыкальный плеер для Windows

**Hox** — лёгкий музыкальный плеер с караоке-режимом, эквалайзером-визуализатором, темами оформления и встроенным лаунчером с автообновлением. Работает на Windows 8.1/10/11 (64-бит), отдельная сборка — для Windows 7 SP1.

> ⚠️ Ранняя бета. Проект развивается, интерфейс и формат данных могут меняться между версиями.

## Возможности

- Караоке-режим с пословной подсветкой (LRC A2 / SYLT-теги) в стиле стриминговых сервисов;
- Синхронизатор текста: автопознавание речи (Whisper) + отделение вокала (Demucs) → синхронизированный текст прямо в тегах трека;
- Пять тем оформления: Aurora, Ember, Classic, Sunset, Emerald;
- Мини-плеер, эквалайзер-визуализатор, редактор плейлистов, сплэш-экран;
- Лаунчер 3.1 (начиная с v0.4.1): схема «лаунчер отдельно — плеер отдельно» — установщик ставит только лаунчер, а плеер ставится из окна лаунчера по кнопке «Обновить / Переустановить» (лёгкий архив `Hox-Player-*.zip` с GitHub Releases, проверка SHA-256); при каждом запуске лаунчер проверяет целостность файлов плеера и пишет «Требуется обновление», если файлов нет, они повреждены или вышла новая версия.

## Установка

### Способ 1 — лаунчер (рекомендуется)

1. Скачайте `Hox-Setup-x.y.z.exe` со страницы [Releases](../../releases);
2. Запустите — Windows может показать предупреждение SmartScreen для неподписанного установщика: «Подробнее» → «Выполнить в любом случае»;
3. Установщик ставит **лаунчер** в `%LOCALAPPDATA%\Hoxmusicp` (runtime Python + `Hox-Launcher.pyw`) и создаёт ярлык «Hox» на рабочем столе и в меню «Пуск»; сам плеер в него НЕ входит;
4. При первом запуске лаунчер проверит файлы и напишет **«Требуется обновление: плеер не установлен»** — нажмите кнопку **«Обновить / Переустановить»**, и он скачает плеер (`Hox-Player-x.y.z.zip` с GitHub Releases), проверит SHA-256 и установит в папку `app` — нужен интернет. Лаунчер сам ничего не качает без вашего нажатия.

### Способ 2 — без интернета на целевой машине

Скачайте с машины с интернетом два файла: установщик `Hox-Setup-*.exe` и архив плеера `Hox-Player-*.zip`. После установки лаунчера положите архив рядом с лаунчером (в папку `app` или рядом с ней) и нажмите «Обновить / Переустановить» — лаунчер найдёт `Hox-Player-*.zip` и поставит плеера автономно.

### Windows 7 SP1

Отдельный установщик `Hox-Setup-Win7-x.y.z.exe` (свой рантайм, совместимый с Win7). Архив плеера общий для обеих сборок; лаунчер Win7-сборки качает тот же `Hox-Player-*.zip`.

## Автообновление

Лаунчер при запуске и по кнопке «Проверить обновления» обращается к GitHub Releases:

```
https://api.github.com/repos/Dima-Xox/Hox-Music-Player/releases/latest
```

Адрес репозитория вшит в лаунчер — автообновление работает сразу после установки, ничего настраивать не нужно. При желании источник можно переопределить в файле `%LOCALAPPDATA%\Hoxmusicp\launcher.ini` (для форков и зеркал):

```ini
[updates]
github_repo = владелец/hox-music-player
```

Шаблон — [launcher.example.ini](launcher.example.ini). Лаунчер 3.1 качает из релиза только архив плеера `Hox-Player-*.zip` (установщики в релизе — для людей, лаунчер их не трогает); версия сверяется по тегу релиза, файл — по контрольной сумме из `Hox-Player-*.zip.sha256`. Если файлов нет, они повреждены или версия старее — лаунчер пишет «Требуется обновление» и ждёт нажатия кнопки «Обновить / Переустановить»: ничего не скачивается без ведома пользователя. При каждом запуске целостность установленных файлов проверяется по манифесту SHA-256 (`player_files.json`), записанному при установке.

## Проверка контрольных сумм (Windows)

```bat
certutil -hashfile Hox-Player-0.4.1.zip SHA256
```

Сравните результат с содержимым `Hox-Player-0.4.1.zip.sha256` из релиза (для установщиков — аналогично).

## Исходники

- `src/hox_music_player.py` — весь плеер (один файл, Python 3);
- `src/Hox-Launcher.pyw` — лаунчер 3.1 (менеджер плеера);
- `src/launcher_shots/` — скриншоты для окна лаунчера.

Запуск из исходников (Windows/Linux/macOS): Python 3.10+, затем `pip install PyQt6 mutagen pygame`, и `python hox_music_player.py`.

## Удаление

«Параметры» → «Приложения» → Hox → «Удалить» — деинсталлятор убирает лаунчер, плеер и ярлыки.
